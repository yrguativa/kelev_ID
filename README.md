# Kelev ID

Identidad digital canina. Sitio estático construido con [Astro](https://astro.build) y [Tailwind CSS v4](https://tailwindcss.com).

## Rutas

| Ruta | Página |
|------|--------|
| `/`  | Landing page — "Kelev ID: El Futuro de la Identidad Canina" |
| `/id` | Pasaporte digital de mascota (Rocky) |

## Diseño

Diseñado en Stitch (proyecto **Kelev Puppy ID**). Colores y tipografía del design system:

- **Colores:** moss-green `#5A6C01`, sprout-lime `#D6ED7C`, deep-navy `#041128`, surface-cream `#FCFAED`
- **Tipografía:** Literata (headlines) + Hanken Grotesk (body)

## Comandos

| Comando | Acción |
|---------|--------|
| `npm run dev` | Servidor de desarrollo |
| `npm run build` | Build a `dist/` |
| `npm run preview` | Preview del build |
